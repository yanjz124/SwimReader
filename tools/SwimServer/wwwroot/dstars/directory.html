CONNECT A DGSCOPE CLIENT

Point your DGScope ScopeServer feed at this server. Each facility streams its own newline-delimited JSON track feed (HTTP stream or WebSocket upgrade on the same URL).

  1. Open DGScope → receiver / ScopeServer settings.
  2. Set the feed URL to the address below, replacing {FACILITY} with a STARS/TRACON identifier from the directory (e.g. A80).
  3. Start the scope — tracks for that facility stream live.
…/dstars/{FACILITY}/updates
