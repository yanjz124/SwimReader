MCA COMMANDS

DATA BLOCK

<1-9> <FLID> — Position data block (numpad layout)
<1-9>/<0-3> <FLID> — Position + set leader length
/<0-3> <FLID> — Set leader line length
<FLID> — Toggle FDB/LDB
// <FLID> — Toggle VCI indicator

FACILITY / SECTORS

XX FAC <id> — Change facility (e.g. XX FAC ZDC)
XX SEC <sectors> — Set sectors, replacing current (e.g. XX SEC 32 33 34)
XX SEC +<s> -<s> — Add/remove individual sectors (e.g. XX SEC +34 -32)
XX SEC ALL | NONE — Select all sectors / clear all
XX FAC <id> SEC <sectors> — Change facility and sectors together
XX VCI ON|OFF — Auto VCI on/off (bare XX VCI reports state)
XX OFFSET ON|OFF — Auto data block offset on/off

QUERIES

QF <FLID> — Query flight plan → Response Area
QD — Clear Response Area
QU [min] <FLID...> — Route display (default 20 min, /M = full)
QU <FLID> — Clear route for flight (toggle)
QU — Clear all route displays
QL [sector...] — Quick Look sectors (force FDB); QL alone clears
NK <apt> ON|OFF — TMU arrival force: force all FDBs up for arrivals to <apt> (NK alone lists, NK OFF clears)
QX <FLID> — Drop track from display

ALTITUDE

QZ <alt> <FLID> — Set assigned altitude (e.g. QZ 350 UAL123)
QZ VFR[/<alt>] <FLID> — Set VFR; QZ OTP = on-top
QZ <floor>B<ceil> <FLID> — Block altitude (e.g. QZ 180B240)
QQ <alt> <FLID...> — Set interim altitude
QQ P<alt> <FLID> — Procedure altitude
QQ <FLID> — Clear interim altitude
QR <alt> <FLID> — Set reported altitude

HSF (HEADING / SPEED / FREE TEXT)

QS <hdg> <FLID> — Set heading (3-digit, 001-360)
QS /<spd> <FLID> — Set speed
QS `<text> <FLID> — Set free text
QS * <FLID> — Clear all HSF; */ = heading, /* = speed
QS <FLID> — Toggle HSF line display

POINT-OUT

QP A [sector] <FLID> — Acknowledge point-out
QP <FLID> — Clear point-out indicator

RANGE / BEARING

LA <loc1> <loc2> — Range/bearing between two locations
LB <fix> <loc> — Range/bearing from fix to location
LC <fix>/<time> <track> — Required speed to reach fix at time

WEATHER

WR R <station> — Display METAR in Response Area (e.g. WR R DCA)
WR <station> — Add weather report (e.g. WR KSTL); toggle to remove
AR <station> — Add altimeter setting (e.g. AR LAX or AR KLAX)

DOT COMMANDS

.FIND <ident> — Highlight fix/navaid/airport on scope
.SID [name] — Toggle SID overlay; no args = list active
.STAR [name] — Toggle STAR overlay; no args = list active
.PROC [name] — Toggle procedure overlay; no args = list active
.NOPROC — Clear all procedure overlays

F-KEY SHORTCUTS

F1=QF   F2=QP   F4=QX   F5=QZ   F6=QU   F7=QL   F8=QQ   F9=QB
Shift+F2=QD   Shift+F7=WR   Shift+F8=QR
