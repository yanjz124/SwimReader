Local edition — first-time setup. Everything runs on your machine; credentials never leave it.
You need your own FAA SWIM SCDS credentials. This tool connects directly to the FAA's public SWIM feeds using a subscription registered to you — it is not shared.
  1. Create an account at the FAA SWIM portal (portal.swim.faa.gov).
  2. Go to SCDS (SWIM Cloud Distribution Service) and request a subscription to the products you want: SFDPS (en-route flights), STDDS (terminal / ASDE-X / TDLS), TFMS (traffic flow / EDCT), TFDM (surface / departure metering), ITWS (weather).
  3. Once approved, each subscription gives you a host, VPN, username, password, and a queue name.
  4. Paste them below. You only need SFDPS to get started — the others are optional and unlock more pages.
All SCDS data is pre-approved for public release by the FAA NAS Data Release Board and is NOT for operational use. This tool is for personal, non-operational visualization only.
